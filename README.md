# 폰트 천국 — Font Haven

AI로 원하는 스타일을 설명하면, 그 느낌에 맞는 **실제 무료 폰트**를 찾아주고 바로 다운로드까지 이어지는 한글·영문 폰트 제작/추천 서비스 프로토타입입니다.

**배포 링크:** https://font-lab-site.vercel.app

---

## 이 프로젝트가 지금의 형태가 된 이유

처음 기획은 "AI가 설명을 분석해서 세상에 없던 새 폰트를 그려주는" 서비스였습니다. 개발 과정에서 실제로 여러 방식을 시도하고 검증한 끝에, 지금의 구조(기존 무료 폰트 중에서 스타일이 맞는 것을 추천 + 실제 폰트 파일 다운로드)로 정리됐습니다. 그 과정을 기록으로 남깁니다.

### 시도했다가 접은 방식

| 시도 | 결과 |
|---|---|
| 이미지 생성 AI(Stability AI, Pollinations 등)로 "가나다" 글자를 직접 그리게 함 | 실제로 호출까지 성공했지만, 한글이 한자 비슷한 모양으로 깨져서 나옴 (이미지 생성 모델은 한글 학습 데이터가 절대적으로 부족함) — 여러 프로바이더에서 동일하게 재현됨 |
| 정부 공공 폰트(KOGL) 자동 다운로드 연동 | 실제 다운로드 엔드포인트까지 찾았지만, 파일이 200MB짜리 zip에 Windows 전용 .exe 설치파일이 들어있는 방식이라 API로 자동화 불가능 |

### 실제로 작동하는 것으로 확정한 방식

1. **AI 폰트 추천**: Groq LLM이 사용자의 스타일 설명(자연어)을 이해해서, 실존하는 무료 Google Fonts 카탈로그 중 가장 어울리는 걸 이유와 함께 추천 (이미지를 그리지 않으므로 깨질 일이 없음)
2. **손글씨 → 실제 폰트 빌드**: 사용자가 직접 캔버스에 쓴 획을 벡터로 기록하고, 자소(초성/중성/종성) 조합 규칙으로 안 쓴 글자까지 자동 생성해서 진짜 `.otf` 파일로 조립 (opentype.js 기반, Node에서 round-trip 파싱 검증 완료)
3. **실제 폰트 파일 다운로드 API**: 선택한 스타일의 정품 Google Fonts 파일을 서버에서 직접 가져와 우리 도메인 이름으로 즉시 다운로드 (`.ttf`/`.woff2` 둘 다 지원, User-Agent 스니핑으로 포맷 제어)

## 지금 사이트에 있는 것

- 8단계 흐름: 입력 → 생성 → 선택 → 커스텀(굵기/크기/색상) → 타이핑 테스트 → 폰트 제작 → 다운로드 → 보관함
- 한글 21종 + 영문 19종, 전부 실제 무료 Google Fonts (SIL OFL 라이선스, 상업적 이용 가능)
- KO/EN 언어 전환 시 스타일 목록·미리보기 문구·다운로드 링크까지 전부 동기화
- `/api/build-font` — 실시간으로 진짜 폰트 파일을 가져와 다운로드시켜주는 서버리스 함수

## 기술 스택

- 순수 HTML/CSS/JS (프레임워크 없음), Vercel Serverless Functions
- Google Fonts API (스타일시트 + 정적 파일 직접 페칭)
- Vercel로 배포 (`vercel --prod`)

## 로컬 실행

```bash
npm install -g vercel
vercel dev
```

## 배포

```bash
vercel --prod
```
