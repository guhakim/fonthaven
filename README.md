# 폰트 천국 — Font Haven

AI가 스타일 설명을 이해해서 어울리는 무료 폰트를 추천하고, 그 자리에서 바로 실제 폰트 파일을 다운로드할 수 있는 한글·영문 폰트 제작 서비스 프로토타입입니다.

**배포 링크:** https://font-lab-site.vercel.app

## 프로젝트 개요

"AI에게 원하는 글씨 느낌을 설명하면 새 폰트를 그려준다"는 기획에서 출발했습니다. 이미지 생성 AI로 한글 글자를 직접 그리는 방식은 여러 차례 검증 끝에 신뢰할 수 없는 결과(한자처럼 깨짐)로 확인되어 방향을 틀었고, 지금은 **Groq LLM이 스타일을 이해해서 실존하는 무료 Google Fonts 중 어울리는 걸 추천**하고, **선택한 스타일의 정품 폰트 파일을 서버가 실시간으로 가져와 즉시 다운로드**시켜주는 구조로 완성했습니다. 8단계 흐름(입력 → 생성 → 선택 → 커스텀 → 타이핑 테스트 → 폰트 제작 → 다운로드 → 보관함)을 네오 브루탈리즘 스타일로 디자인했습니다.

## 기술 스택

- **마크업/스타일**: HTML5, 순수 CSS (프레임워크 없음)
- **폰트**: Google Fonts — 한글 21종 + 영문 19종 (전부 SIL OFL, 상업적 이용 가능)
- **인터랙션**: Vanilla JavaScript
- **백엔드**: Vercel Serverless Functions (Node.js)
- **배포**: Vercel

빌드 도구 없이 순수 HTML/CSS/JS로 제작되어 별도 설치 없이 실행 가능합니다.

## 파일 구조

- **index.html**: 8단계 전체 UI(입력/생성/선택/커스텀/타이핑/제작/다운로드/보관함)와 스타일 데이터, 인터랙션 로직
- **api/build-font.js**: 선택한 폰트의 정품 파일(.ttf/.woff2)을 Google Fonts에서 실시간으로 가져와 다운로드시키는 서버리스 함수
- **.gitignore**: `.vercel`, `.omc`, `node_modules` 제외

## 주요 기능

1. **01 입력**: 원하는 스타일을 문장으로 입력 (KO/EN 전환 가능, 이 텍스트가 이후 모든 미리보기에 그대로 반영됨)
2. **02 생성**: 실제 진행률 타이머 애니메이션
3. **03 선택**: AI가 스타일에 맞는 폰트를 실제 렌더링으로 보여줌 (한글 21종 / 영문 19종 중)
4. **04 커스텀**: 굵기·크기·기울기·색상 실시간 조절
5. **05 타이핑**: 완성된 스타일로 직접 타이핑 테스트
6. **06 폰트 제작**: 선택한 스타일 요약
7. **07 다운로드**: `.TTF`/`.WOFF2` 버튼 클릭 시 `/api/build-font`가 실제 폰트 파일을 즉시 전달
8. **08 보관함**: 완성한 스타일 목록

## 개발 기록 — 시도했다가 접은 방식

| 시도 | 결과 |
|---|---|
| 이미지 생성 AI(Stability AI, Pollinations)로 "가나다" 글자를 직접 그리게 함 | 실제 API 호출은 성공했지만 한글이 한자 비슷한 모양으로 깨져서 나옴 — 이미지 생성 모델의 한글 학습 데이터 부족이 원인이며 여러 프로바이더에서 동일하게 재현됨 |
| 정부 공공 폰트(KOGL) 자동 다운로드 연동 | 실제 다운로드 엔드포인트까지 찾았지만, 파일이 200MB짜리 zip 안에 Windows 전용 .exe 설치파일이 들어있는 방식이라 API 자동화 불가능 |
| 손글씨 샘플 한 장으로 완성형 한글 전체 자동 생성 | 검증된 신뢰도가 낮아 보류 — 대신 사용자가 자소(초성/중성/종성)를 직접 쓰면 나머지를 조합하는 방식으로 별도 엔진(`hangul-font-lab`)에서 검증 완료 |
